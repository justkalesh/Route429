Built for developers

Everything you need to stop worrying about rate limits and start building.

01 · rotation

Auto key rotation

When a key hits 429, Route429 instantly swaps to the next one in the pool. Your users never see an error.

02 · dashboard

Multi-project dashboard

Create separate projects for each app. Each gets its own key pool, provider config, and endpoint URL.

03 · infra

Edge-deployed

Runs on Cloudflare Workers — 300+ locations worldwide, sub‑millisecond cold starts.

04 · security

Secure by design

API keys are encrypted at rest in Cloudflare KV. Never exposed in responses or client code.

05 · access

Full CORS support

Configure allowed origins per project. Works seamlessly with browser-based apps.

06 · providers

Provider presets

One-click setup for OpenAI, Gemini, and Anthropic. Or point it at any custom API endpoint.

How it works

Get up and running in under a minute.

  1. 01

    Create a project

    Sign up, give your project a unique name, and pick your API provider — or enter a custom endpoint.

  2. 02

    Add your API keys

    Paste in your keys, as many as you want. Route429 cycles through them automatically.

  3. 03

    Wire your app

    Replace your API base URL with your Route429 project URL. That's it — no other code changes needed.
