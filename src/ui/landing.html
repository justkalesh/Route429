Integration Guide

Drop-in replacement for standard API endpoints.

1. Standard HTTP Requests (cURL, fetch, Python)

Simply replace the provider's base URL with your Route429 project URL. No API keys needed in the header!

// cURL Example
curl -X POST "https://route429.dev/p/YOUR_PROJECT/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Say hello!"}]}'
// Browser fetch (JavaScript/TypeScript)
const response = await fetch('https://route429.dev/p/YOUR_PROJECT/v1beta/models/gemini-1.5-flash:generateContent', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ contents: [{ parts: [{ text: "Say hello!" }] }] })
});
# Python Requests
import requests
response = requests.post(
    "https://route429.dev/p/YOUR_PROJECT/v1/messages",
    json={"messages": [{"role": "user", "content": "Say hello!"}]}
)

2. Using Official SDKs (OpenAI, Gemini, Anthropic)

SDKs usually require an API key to initialize. Pass a dummy key, and override the baseURL parameter to point to your proxy.

// OpenAI SDK (Node.js)
import OpenAI from 'openai';
const openai = new OpenAI({
  apiKey: 'dummy-key', // Route429 injects the real one
  baseURL: 'https://route429.dev/p/YOUR_PROJECT/v1'
});
// Google GenAI SDK (Node.js)
import { GoogleGenAI } from '@google/genai';
const ai = new GoogleGenAI({ 
  apiKey: 'dummy-key',
  httpOptions: { baseUrl: 'https://route429.dev/p/YOUR_PROJECT' }
});

3. Agentic AI Context (Cursor, Claude, ChatGPT)

If you're using an AI coding assistant to refactor your codebase to use Route429, just paste this prompt into your IDE chat:

Copy & Paste to your AI Assistant I am migrating my application to use Route429, an API key rotation proxy. Please review my codebase and do the following: 1. Find all instances where I am initializing an AI provider SDK (OpenAI, Anthropic, Gemini) or making raw HTTP fetch requests to their APIs. 2. Remove any direct usage of my secret API keys from the client code. 3. Replace the provider's standard base URL with my Route429 proxy URL: `https://route429.parth-ie-kalash.workers.dev/p/MY_PROJECT_NAME` 4. If an SDK strictly requires an API key parameter to initialize, pass a dummy string like `"route429-managed"`. 5. Ensure CORS headers are not being stripped by custom interceptors, as Route429 handles CORS automatically. Do not change the structure of the payloads or the models used, only the URL and authentication mechanism.
